# Archive Rules

Archive root → `/media/oscar/Data/workspace/archive`

## Archive Project

At user request:

1. Update the project status in the file `PROJECT_STATUS.md`.
2. Ensure project files are complete.
3. Move project from `projects/` to `archive/`.
4. Preserve project structure and documentation.

## Restore Project

At user request:

1. Locate project in → `archive/`.
2. Move project back to → `projects/`.
3. Continue using project workflow.

## Rules

- Do not delete archived projects.
- Do not modify archived projects unless restoring them.
- Keep original project structure.
- Preserve `PROJECT_STATUS.md` when archiving projects.
